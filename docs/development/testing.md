# Testing

The project uses `pytest` for testing.

## Running Tests

To run the full test suite:

```bash
pytest
```

## Test Structure

- `tests/test_cbir_e2e.py`: End-to-end tests for CBIR.
- `tests/test_panel_extraction_e2e.py`: End-to-end tests for panel extraction.
- `tests/test_user_operations.py`: Tests for user management.
